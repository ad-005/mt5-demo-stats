# MT5 Demo Account Trading Statistics

---

The goal of this project is to create an overview of trading performance on MetaTrader 5 demo accounts,
as I didn't find the built in trading statistics which MetaTrader 5 natively offers descriptive enough.

The statistics currently (and to be) implemented are inspired by the statistics which prop firms offer for
their challenges.

---

## Features
- **Overall statistics**:
  - Trading bias (bullish/bearish)
  - Winrate
  - Per session winrate
  - Overall statistics per account (optional)
- **Trade filtering by**:
  - Start/End date
  - Account (Login)
  - Session
- **Manual demo account addition/removal**
